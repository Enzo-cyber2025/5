# Entrega retirada

O APK anterior foi removido porque era apenas um bootstrap que baixava componentes na primeira execução e não incorporava o Depth Anything 3 Small exigido. Ele não deve ser tratado como a entrega final do projeto.

Não há APK publicado enquanto as especificações tecnicamente incompatíveis não forem corrigidas: o DA3-Small indicado é monocular e produz profundidade relativa, mas o requisito exige profundidade estéreo de dois sensores e distância absoluta em metros.
